# Короткий отзыв перед работой в модуле 2

Решение Александра от 23 ноября 2026: в понедельник после занятия запросить короткий фидбек внутри LMS и открывать модуль 2 после отправки. Для первого запроса отдельно назначено 23 ноября, 15:00:35 Europe/Lisbon («через 45 минут»). Раньше этого времени включать запрос нельзя.

Миграция 019 создаёт настройку только для модуля 2. Обычное время — следующий понедельник после занятия, 09:00 Europe/Lisbon, из текущей даты занятия в `lms.sessions`; для первого запуска применяется дополнительная нижняя граница выше. Время хранится в `lms.module_feedback_prompts.request_after`, не зависит от часового пояса браузера. Остальные модули не включаются автоматически.

Один именной комментарий; оценка 1–5 необязательна. Любой содержательный отзыв о модуле 2, включая ранее отправленный и отрицательный, открывает доступ; общий отзыв о курсе его не заменяет. Ответы видят автор и администраторы. Прямые запросы к материалам, видео, заданиям, вопросам и сохранённым версиям ограничены RLS до отзыва; существующие данные не удаляются. Приватные собственные загрузки остаются собственностью участника.

Уведомление `feedback.requested` имеет `channel=in_app`: оно сразу получает внутренний статус доставки и не попадает в SMTP-очередь или экран Email. Даже ручное изменение статуса не разрешает отправку такого уведомления по email. Планирует существующий почтовый worker, а также загрузка workspace после наступления срока; при простое запрос появляется после восстановления, без истечения окна. Повторы не создают дубли благодаря ключу «модуль + участник». После ответа запрос отмечается прочитанным. Пользователи без действующего доступа и сотрудники не получают запрос; активные QA-профили должны быть исключены при проверке рабочего списка до активации.

При открытом кабинете данные обновляются раз в минуту и при возвращении в окно, если нет несохранённого текста. На модуле 2 показана форма вместо учебных действий; на других страницах — приглашение перейти к форме. Разрешение браузера на системные push-уведомления не требуется.

## Выпуск и проверка

Перед установкой: проверить CI, создать штатную резервную копию, сверить текущий выпуск и расписание Module 2. Применить миграцию без seed. Проверить наличие ровно одной строки `module=2` и нужного `request_after`; сохранить возможность отменить запрос удалением этой настройки административным подключением, не трогая отзывы и учебные данные. Старый выпуск сохранить для отката. На синтетическом участнике проверить интерфейс, прямой файл, черновик, отправку, перезагрузку и отсутствие повторного запроса; реальные отзывы за участников не отправлять.

При откате на старый интерфейс сначала отключить запрос удалением настройки только модуля 2, сохранив отзывы и учебные данные. Иначе новые RLS-ограничения продолжат закрывать модуль после возврата старого кода. Перед выпуском Next.js обновлён до 16.4.5: аудит npm не обнаружил уязвимостей, сборка завершилась успешно.

Локальный тест `tests/feedback-gate.test.ts` проверяет границу времени, закрытие прямых команд/файлов, доступность других модулей, сохранность черновиков, отсутствие дублей и SMTP, зачёт ранее отправленного ответа и необязательность положительной оценки.

Подготовка кода не означает установку или доставку. Рабочий статус и оставшиеся блокеры: `../README.md` в папке задачи `2026-11-23_module-2-feedback`, вне Git-репозитория приложения.
