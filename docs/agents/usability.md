# Правила интерфейса

Английский адаптивный web. Даты — CET плюс часовой пояс участника; один общий поток. Основные ширины проверки: 360, 390 и 1440 CSS px. Chrome и Safari; реальное устройство проверяется отдельно от изменения ширины окна.

- Одно понятное главное действие по текущему состоянию.
- Кнопки и области нажатия минимум 44 CSS px; видимый фокус.
- Ошибка рядом с частью ответа и переход к первой ошибке; исправленные данные не должны оставлять ложную ошибку.
- При сбое сети/сессии текст сохраняется. Конфликт не перезаписывает другую версию.
- Отправка не дублируется при повторе; принятая сдача остаётся в истории.
- Выбранный модуль сохраняется в URL, reload и Back/Forward восстанавливают раздел.
- Подсказка следующего действия соответствует Submitted/In review/Accepted/Needs revision.
- В кабинете участника нет внутренних UUID и настроек инфраструктуры.

| Действие | Исправление / обратное действие |
|---|---|
| Сохранить черновик | Редактировать и сохранить снова |
| Прикрепить файл | Убрать из черновика |
| Отправить работу | Новая версия; исходная сдача остаётся |
| Взять на проверку | Опубликовать решение; чтение само не меняет статус |
| Опубликовать решение | Исправление с причиной и историей |
| Выйти | Повторный вход; несохранённый текст требует предупреждения |
