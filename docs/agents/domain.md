# Предметная модель

Один общий поток, без подгрупп. Участник владеет личным проектом и приватными черновиками; назначенный эксперт видит отправленные версии, администратор управляет доступом и содержимым курса.

Отправка создаёт неизменяемый снимок. Состояния сдачи: Submitted → In review → Accepted / Needs revision. Решение можно опубликовать и сразу из Submitted. Новая версия имеет свой цикл; исправление опубликованного решения требует причины и сохраняет прежнюю запись.

Самооценка — отдельная приватная сдача со статусом Received в интерфейсе; эксперт не принимает по ней решение как по ДЗ. Итоговый пакет содержит выбранные собственные версии и остаётся связан с проектом. Отметка изученного материала, экспертное решение и решение по сертификату не равны друг другу.

Полные источники и их расположение — [DEVELOPMENT](../DEVELOPMENT.md). Перед изменением предметных правил свериться с актуальным ТЗ.
