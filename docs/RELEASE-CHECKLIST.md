# До запуска первого потока

Состояние на 1 ноября 2026. Успешные локальные тесты не означают готовность открыть LMS участникам.

## Репозиторий

- [x] Выделен состав приложения; секреты, исторические QA-артефакты, архивы и временные ссылки исключены.
- [x] Убраны записанные пароли из локального QA-отчёта; его содержимое не входит в первый коммит.
- [x] Подготовлен workflow типов, тестов и сборки без рабочих секретов.
- [ ] Создать приватный удалённый репозиторий после отдельного указания; проверить первый CI-прогон.
- [ ] Заменить/отключить ранее записанные QA-пароли в Supabase перед рабочим запуском. Редактирование документа не отзывает действующий пароль.

## До приглашения участников

- [ ] Проверить ресурсы и существующие сервисы Hetzner, настроить постоянный запуск приложения и почтового обработчика.
- [ ] Домен, HTTPS, публичный `APP_ORIGIN`, адреса возврата Supabase Auth.
- [ ] Разобрать 16 pending-уведомлений аудита: 10 тестовым адресатам, 6 реальным. Не включать доставку до проверки событий.
- [ ] Настроить почту входа Supabase Auth и почту курса (SMTP или Brevo); проверить приглашение и уведомление на контрольном адресе.
- [ ] Выделить рабочее подключение БД с минимальными правами, отделив от роли миграций.
- [ ] Проверить резервирование и восстановление БД вместе с файлами, мониторинг ошибок и очередей.

## До начала обучения

- [ ] Назначить настоящих экспертов: в момент аудита все девять заданий были назначены тестовому эксперту.
- [ ] Внести сроки сдачи и проверки, правила опоздания, график открытия заданий.
- [ ] Опубликовать стартовые материалы, заменить тестовые ссылки, добавить видео с субтитрами и ссылки на встречи.
- [ ] Сохранить подтверждённый календарь: 15 ноября — 27 декабря 2026, семь воскресений в 15:00 CET.
- [ ] Пройти на рабочем стенде участник → сдача → эксперт → доработка; отдельно самооценки, изображения и итоговый пакет.
- [ ] Проверить изоляцию работ, отзыв доступа к файлам, обычное приглашение, реальный телефон/Safari и ожидаемую нагрузку.

## Остатки реализации

- [ ] Увеличить Feedback/Notifications с 38 до минимум 44 CSS px и проверить 360/390 px.
- [ ] Определить сроки закрытия оставшихся требований: защищённое видео, история материалов, переназначения из интерфейса, исправление Late, архив участника, решение по сертификатам, комментарий команды к самооценке, файловые фоновые операции.

В первой версии один общий поток 15–25 человек. Тьютор, подгруппы, автоматическая AI-проверка и встроенная оплата не требуются.
